4. Name: `Dobbie Web`

   - `http://localhost:3000` (dev)

   - `https://app.dobbie.com/auth/google/callback` (prod)

## Phase 3: Handle Platform-Specific Auth (Web)

### 3.1 Google Sign-In (Web)

| Flutter | Web |
|---|---|
| `google_sign_in` package | Google Identity Services (GSI) JS SDK |
| Native popup | One-tap or button flow |

**Implementation:**
```tsx
// In your sign-in page
useEffect(() => {
  // Load GSI script
  const script = document.createElement('script');
  script.src = 'https://accounts.google.com/gsi/client';
  script.async = true;
  document.body.appendChild(script);
}, []);

const handleGoogleSignIn = () => {
  // Use the new GSI button or programmatic flow
  window.google.accounts.id.prompt();
};

// Callback receives credential response
const handleCredentialResponse = (response: any) => {
  // Send response.credential (ID token) to backend
  // POST /api/v1/auth/google with { id_token: response.credential }
};
```

**Backend:** No change needed — same endpoint `POST /api/v1/auth/google`

### 3.2 LinkedIn OAuth (Web)

| Flutter | Web |
|---|---|
| `flutter_web_auth_2` with custom scheme | Standard browser redirect |

**Flow:**
1. User clicks "Connect LinkedIn" on web
2. Frontend calls `GET /api/v1/auth/linkedin/authorize?redirect_url=https://app.dobbie.com/auth/linkedin/callback`
3. Backend returns LinkedIn's OAuth URL with your redirect baked in
4. User redirected to LinkedIn, authorizes
5. LinkedIn redirects to your callback URL with `?code=...&state=...`
6. Frontend reads code, calls `GET /api/v1/auth/linkedin/callback?code=...&state=...`
7. Backend exchanges code for tokens, redirects to app with success/error

**Backend change needed:**
- `POST /auth/linkedin/authorize` to accept optional `redirect_url` parameter
- `GET /auth/linkedin/callback` to handle the redirect properly for web

### 3.3 File Upload (PDF)

| Flutter | Web |
|---|---|
| `file_picker` package | Standard `<input type="file" accept=".pdf">` |

**No backend changes** — same `POST /api/v1/profile/upload-pdf` endpoint.

## Phase 5: Flutter WebView Shell

**Replace current Flutter app with minimal wrapper:**

```yaml
# pubspec.yaml - minimal
dependencies:
  flutter:
    sdk: flutter
  webview_flutter: ^4.4.0
```

```dart
// main.dart - ~50 lines
import 'package:flutter/material.dart';
import 'package:webview_flutter/webview_flutter.dart';

void main() => runApp(const DobbieApp());

class DobbieApp extends StatelessWidget {
  const DobbieApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Dobbie',
      home: const WebViewScreen(),
    );
  }
}

class WebViewScreen extends StatefulWidget {
  const WebViewScreen({super.key});

  @override
  State<WebViewScreen> createState() => _WebViewScreenState();
}

class _WebViewScreenState extends State<WebViewScreen> {
  late final WebViewController _controller;

  @override
  void initState() {
    super.initState();
    _controller = WebViewController()
      ..setJavaScriptMode(JavaScriptMode.unrestricted)
      ..loadRequest(Uri.parse('https://app.dobbie.com'));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: SafeArea(
        child: WebViewWidget(controller: _controller),
      ),
    );
  }
}
```
